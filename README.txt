FlowChart Studio - PNG Import Fix

Replace your existing index.html, style.css, and script.js with the matching files in this folder.
Keep all three files in the same folder.

PNG import needs an internet connection to load OpenCV.js and Tesseract.js the first time.
When asked whether to keep the original PNG as a faint reference, choose Cancel for an editable-objects-only canvas (recommended). Choose OK only if you want the reference image left behind.

After opening the app, use File > Import PNG flowchart. Detected shapes and OCR text are approximate and may need manual correction; automatic reconstruction cannot guarantee perfect recognition for every image.
